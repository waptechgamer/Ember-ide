Getting Started

Launch Ember IDE in Seconds

Follow these simple steps to run Ember IDE locally on Linux, Windows, or macOS.

01

Install Dependencies

Install PyQt5, QScintilla, and required LSP/AI helper packages:

pip install -r requirements.txt
02

Launch Main Application

Run the entry point `main.py` using Python 3.10+:

python main.py
03

Run Verification Suite

Execute the automated headless smoke test suite:

python tests/smoke_test.py
